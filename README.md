# DogWatch

Утилита для мониторинга активных процессов залогиненных пользователей на Windows-машине. Каждые 5 минут собирает список процессов и сохраняет их в CSV-файл.

## Как запустить

Собрать:
```bash
go build -o dogwatch.exe .
```

Запустить:
```bash
./dogwatch.exe
```

Логи пишутся в папку `output/`.
